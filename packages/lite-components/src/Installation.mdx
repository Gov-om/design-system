# Lite Components

Lite Components are a class-based alternative to the GUP web components.
Instead of using custom elements like `<gup-button>`, you apply CSS classes to native HTML elements like `<button>` and `<a>`.

This approach is useful when:

- You need to style native HTML elements without shadow DOM
- You want a lighter-weight integration with minimal JavaScript
- Your project setup doesn't support custom elements
- You prefer working with standard HTML elements

They ship as a separate package, `@govom/lite-components`, so you don't have to install the web components (`@govom/components`) to use them.

> Lite Components are currently in **Beta**. The API may change in future releases.

## Installation

```bash
npm install @govom/lite-components
```

## Importing styles

Each Lite Component has its own CSS file that must be imported. Import only the components you use:

```css
/* In a CSS file (PostCSS or bundler required) */
@import "@govom/lite-components/button/button.css";
```

```javascript
// Or in a JavaScript/TypeScript entry point
import '@govom/lite-components/button/button.css';
```

```html
<!-- Or as a link tag -->
<link rel="stylesheet" href="/node_modules/@govom/lite-components/dist/button/button.css">
```

You also need the design tokens for colors, spacing, and typography to work correctly. Import the `tokens` stylesheet, which contains only CSS variables and `@font-face` declarations (no web-component base or reset styles):

```css
@import "@govom/lite-components/tokens";
```

If you also use the web components elsewhere and already import `@govom/components/styles`, that is sufficient on its own - it includes everything in `tokens` plus a CSS reset - and you can skip the import above.

## Usage

### Pure HTML/CSS

Apply the CSS classes directly to native HTML elements:

```html
<button class="gup-button gup-button--primary">Primary Button</button>
<button class="gup-button gup-button--secondary">Secondary Button</button>
<a href="/page" class="gup-button gup-button--text">Text Link</a>
```

### TypeScript utility

Import the utility class for programmatic usage:

```typescript
import { GupButton } from '@govom/lite-components';

// Apply styles to an existing element
const btn = document.querySelector('button');
GupButton.apply(btn, { appearance: 'primary' });

// Create a new styled button
const newBtn = GupButton.create({ appearance: 'secondary', disabled: true });
newBtn.textContent = 'Disabled Button';
document.body.appendChild(newBtn);

// Get a class string for use in templates
const className = GupButton.getClassName({ appearance: 'danger' });
// => "gup-button gup-button--danger"
```

## Templates

Page-level templates combine structural layout classes with Lite Components to produce full-page compositions without any web components.

Import the template CSS alongside the component CSS files it depends on:

```javascript
import '@govom/lite-components/button/button.css';
import '@govom/lite-components/checkbox/checkbox.css';
import '@govom/lite-components/templates/service-start.css';
```

The template CSS provides layout classes that replace the corresponding web component wrappers:

| Web component          | Lite class                                   |
| ---------------------- | -------------------------------------------- |
| `<gup-header>`         | `.gup-lite-header` + `.gup-lite-header__nav` |
| `<gup-content-header>` | `.gup-lite-content-header`                   |
| `<gup-wizard-main>`    | `.gup-lite-wizard-main`                      |
| `<gup-wizard-footer>`  | `.gup-lite-wizard-footer`                    |

See the [Service Start template story](?path=/story/lite-components-wip-templates-service-start--default) for a complete working example.

## Usage without npm

If your project cannot use npm, you can use the CSS files directly. You need two stylesheets: the **design tokens** (for colors, spacing, and typography) and the **component CSS**.

### Option 1: Link to hosted CSS files

The `@govom/lite-components` package is published on npm, so you can point directly at a CDN that mirrors npm packages (e.g. jsDelivr) instead of hosting the files yourself:

```html
<!-- 1. Design tokens (required) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@govom/lite-components/dist/tokens.css">

<!-- 2. Shared styles (required alongside relevant components) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@govom/lite-components/dist/forms.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@govom/lite-components/dist/utils.css">

<!-- 3. Component CSS - add only what you need -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@govom/lite-components/dist/accordion/accordion.css">
```

### Then use the HTML directly

No JavaScript or build tools required:

```html
<button class="gup-button gup-button--primary">Submit</button>

<label class="gup-checkbox">
  <input type="checkbox" class="gup-checkbox__input" />
  <div class="gup-checkbox__check-mark">
    <div class="gup-checkbox__check-mark-inner"></div>
  </div>
  <div class="gup-checkbox__text-container">I agree</div>
</label>
```
