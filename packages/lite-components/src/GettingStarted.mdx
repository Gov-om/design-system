# Getting started

> Lite Components are a work in progress and ship as a Beta for real user testing. Please use them only after agreeing on scope with the Nortal team.

Lite Components are a class-based way to use the GUP design system on native HTML elements (for example `<button class="gup-button">` instead of `<gup-button>`). They exist for teams that cannot use the web components - no custom elements or shadow DOM, or a build that does not support them.

## Beta status

This is an early Beta released so real projects can try it and give feedback before a stable version. While it is Beta:

- The API can change between releases - class names, markup structure, and tokens may be adjusted based on what we learn.
- Coverage is partial. Not every component is available yet, and some are still being finalised.
- Pagination and dropdown are not part of this release yet.

## Use it only after agreement with the Nortal team

Before using Lite Components in a real service, please reach out to the Nortal design system team so we can:

- confirm the components you need are ready for your use case,
- agree on the Beta version to pin, so a later change does not surprise you,
- support you during integration and hear your feedback.

You can reach the team through the design library [support channel](https://github.com/Gov-om/design-system/discussions).
Once we have agreed on scope, head to Installation to add the package and import only the styles you need.
